# The application path: coherent disambiguation (exp26 design, 2026-08-04)

## Why every other path dies, in one line each
- Beat classical at classification/similarity: dead — measured ourselves, classical wins at every budget; at scale the "power of data" results say the advantage evaporates.
- Quantum search over embeddings: dead — quadratic speedup loses to classical indexing constants.
- Quantum meaning: dead — we proved geometry comes from parameter structure, not semantics.

## The surviving candidate: hold ALL readings at once
A sentence with k ambiguous elements (senses, case endings, attachments) has
2^k..S joint readings. Classical NLP never represents that joint distribution:
it prunes (beam), collapses early (greedy taggers), or approximates
(mean-field/neural marginals). Exact conditioning of the joint reading
distribution on GLOBAL consistency constraints is exponential classically in
the worst case (dense coupling; fine for trees via DP — that honesty stays in
every version of this claim).

A quantum register holds the full joint distribution with LINEAR qubit cost
(one control per ambiguous element — exp24b is the k=1 case), the grammar
circuit couples readings compositionally, and post-selection CONDITIONS the
distribution on consistency — hard constraints (agreement ancillas) and soft
ones (compositional interference on the sentence wire) in one mechanism.

Two structural advantages specific to language:
1. NO QRAM WALL. QML usually dies loading data. Here the superposition is
   GENERATED by a compact grammar+lexicon description (small circuits), not
   loaded from a database. Ambiguity is generative.
2. Arabic is the maximal instance. Undiacritized text is the densest
   naturally-occurring ambiguity system in any major language — tashkeel
   restoration IS joint global disambiguation (case endings ↔ syntactic
   roles ↔ each other). Neural diacritizers are excellent on average and
   fail on exactly the globally-coupled tail: poetry, legal text, classical
   corpora, Quranic commentary — the high-value, error-intolerant domains.

## Target application (if the physics scales)
Hard-tail joint disambiguation: tashkeel of poetry/legal/classical text, MT
of undiacritized Arabic, morphological analysis of classical corpora — as an
exact-inference back-end invoked on the cases where classical models
disagree with themselves.

## The load-bearing assumption to TEST NOW (exp26)
Everything above lives or dies on one number: the POST-SELECTION SUCCESS
PROBABILITY p_post as a function of k and constraint density. If p_post
decays exponentially with a bad base, physical repetitions explode and the
path is closed — publish the boundary. If it decays gently for
grammar-shaped constraint graphs, the path is open and the sizing table
tells us what machine runs k=20.

## Exp26 Phase 0 (simulation, our own engine, k = 1..8)
Planted-instance generator: k binary reading slots, planted truth r*;
misleading priors on ⌈k/2⌉ slots (P(correct)=0.35 — greedy MUST fail);
constraint graph = chain (tree case) and chain+chords (loopy case, density
dial); constraints = pairwise parity matching r*.
Circuit: controls prepared by priors (Ry); per-edge XOR ancilla computed,
post-selected, discarded (sequential — ≤ k+2 live qubits); OPTIONAL soft
layer: sentence wire in |+>, reading-controlled CRz phases, H, post-select
(compositional interference evidence — the exp1 mechanism reused as soft
conditioning).
Conditions: hard-only, soft-only, hard+soft.
Measures vs k and density:
 1. p_post (THE number) + fitted decay base
 2. exactness check: quantum conditional distribution == classical posterior
    (validation gate, must pass to machine precision)
 3. MAP accuracy: quantum-conditioned vs planted; greedy baseline; ICM
    (hill-climb) baseline — greedy must fail on misleading slots, the
    conditioned distribution must not
 4. samples-to-MAP (from the exact distribution's probability gap)
 5. sizing extrapolation: logical qubits + repetitions for k = 10/20/50 —
    the "what would the machine need to be" table, stated plainly
Classical positioning stated in results: trees are classically easy (DP);
the quantum case rests on loopy density + soft interference evidence +
generative superposition. If loopy p_post is no better than tree p_post,
say so.

## Pre-registered outcomes
- O1: hard-only conditional == classical posterior exactly (sanity; if this
  fails the implementation is wrong).
- O2: conditioned MAP recovers r* where greedy fails (the point of
  conditioning).
- O3: p_post(k) decay base measured; feasibility verdict = repetition count
  at k=20 under three hardware assumptions (10^3, 10^6, 10^9 shots/hr).
- O4 (open): does the soft interference layer add evidence beyond the hard
  constraints (accuracy or p_post improvement)? Either answer is a finding.
